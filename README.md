# TEP process monitoring

Status: work in progress. PCA baseline on the Tennessee Eastman Process, with an AI extension planned.

## Setup
Requires Python 3.10+ and git.

    git clone <repo-url>
    cd tep-monitoring
    .\setup.ps1
    .venv\Scripts\Activate.ps1

Linux/macOS: python3 -m venv .venv, then source .venv/bin/activate, then pip install -r requirements.txt
